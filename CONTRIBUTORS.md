# Contributors

Cadence exists because of the work recorded here. This file credits roles and
kinds of contribution, not just merged patches — triage, documentation, testing
and reporting all count.

"eventually". If you contributed and are not listed, that is a bug: open an
issue and it will be fixed.

## Build automation

Cadence is developed with AI coding agents working from a written build
process. The agents are credited as tooling rather than as people: they act on
the maintainer's behalf, with no independent standing in the governance model
(see [`GOVERNANCE.md`](GOVERNANCE.md)), under the account identity
`Cadence Dev <dev@example.com>`. Every agent change arrives as a pull request
with CI evidence, reviewed like any other change.

## How to be added

- Get any contribution merged — a fix, a test, a documentation change, a
  reproduction on an issue, a triage.
- Or take on one of the areas listed in [`GOVERNANCE.md`](GOVERNANCE.md)
  (accessibility, documentation, interchange, security triage).

Then say so in the pull request or issue, and you will be added here — with the
role you want attributed.
